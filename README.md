# IoT Thesis Project

This repository groups the two related thesis components: `pgh-code` (the thesis implementation) and `bcacprod/iot` (the access-control integration).

The `pgh-code` snapshots in Thesis I and Thesis II were byte-for-byte identical across the checked text and configuration files, so the Thesis I copy is used here. Generated evaluation results, local databases, dependency folders, archives, and machine-specific credentials are excluded. Environment templates are sanitized; set your own values locally before running the projects.

The thesis folders also contained full checkouts of third-party access-control projects. Those upstream copies are not duplicated here. See [Access_Control_Mechanism](https://github.com/batuhantnrkulu/Access_Control_Mechanism) and [blockchain-access-control](https://github.com/batuhantnrkulu/blockchain-access-control) for their source. Your already-published component repository is [blockchain-access-control_testing](https://github.com/hemantmpx/blockchain-access-control_testing).
